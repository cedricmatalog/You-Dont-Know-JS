#### Priority Issues

**[P1] Library hero outranks the shelf.**
- **Why it matters**: The operator already has the markdown. The first screen is a landing page. The six books sit below a 9vw title and a CTA that does not mean the shelf. Detector: 11 hits on `#/`, including ~99ch lines and seven wide card shadows.
- **Fix**: Make the shelf the first decision. Shrink or drop the campaign lockup. Point “Browse the shelf” at `.shelf` or remove it. Keep Continue as the only large action when `store.last` exists.
- **Suggested command**: `/impeccable distill`

**[P1] Progress is mute and position is half-saved.**
- **Why it matters**: `.track i` and `.marble` are color-only; `.reader-progress` is `aria-hidden`. `setLast(..., scroll)` never feeds restore. Continue opens the chapter top. Done flips at 0.92 with no label or undo. Sam cannot hear “42% through Chapter 3.”
- **Fix**: Restore `last.scroll` (or heading). Name progress in text (“Ch 3 of 8”). Expose a live region or meter. Do not rely on gold vs empty.
- **Suggested command**: `/impeccable harden`

**[P1] Mobile chrome hides place and labels.**
- **Why it matters**: ≤640px hides `.brand-name`; ≤980px hides `.topbar-title`. Search and TOC are icon-only. Casey cannot see which book; five 44px controls crowd the top, not the thumb zone.
- **Fix**: Keep a short book+chapter label visible. Text for Search. Move type/theme into a single Read menu or bottom bar. Leave pager at the bottom.
- **Suggested command**: `/impeccable adapt`

**[P2] “Browse the shelf” and dual spine/Read.**
- **Why it matters**: Ghost button goes to Get Started’s book page. Each shelf row is two destinations. Jordan will mis-click; Start skips Foreword/Preface without saying so.
- **Fix**: One primary per row. Rename or retarget the ghost CTA. Put front matter in the Start path or say that Start skips them.
- **Suggested command**: `/impeccable clarify`

**[P2] Accelerators and chrome have no teaching surface.**
- **Why it matters**: `/`, Cmd+K, `[` `]` exist and are unpublished. Theme cycles Auto/Day/Night without listing them. Bad hashes never explain themselves.
- **Fix**: One-line hint in search. Theme as three labeled options. Unknown route: “No book named X — back to library.”
- **Suggested command**: `/impeccable onboard`
